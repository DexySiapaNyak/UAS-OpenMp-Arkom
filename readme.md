# Parallel Array Sum Using OpenMP

## Anggota
- Michael Febriano Juns
- Ryan Ahmad Maulana

## Deskripsi

Program ini membandingkan performa penjumlahan array secara sequential dan parallel menggunakan OpenMP.

## Fitur Yang Ada

- Sequential Processing
- Parallel Processing dengan OpenMP
- Benchmark waktu eksekusi
- Perhitungan speedup

## Cara Menjalankan Program
Compile:

g++ main.cpp -fopenmp -O2 -o main

Run:

.\main.exe
